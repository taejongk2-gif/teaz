message_count = 사이트가 "누적 대화 N회"로 표시하는 값. 유저 발신 메시지 1건당 +1. 대화창 수·이용자 수가 아님. 첫 샘플 값에는 수집 시작 전 누적분이 포함됨

샘플(가짜) 데이터를 표시 중입니다. data.js 가 생성되면 자동으로 실제 값으로 바뀝니다.

시간별 증가량 (캐릭터별)

KST 정시 기준 구간별 message_count 증가분. 막대 위 숫자와 선은 합산. 작품 색상군 안에서 밝기로 캐릭터 구분

누적 메시지 추이

수집 샘플별 누적 message_count. 누적 상위 6개 캐릭터만 색상 강조(작품 색상), 나머지는 회색

일단위 대화수

KST 자정 기준 일별 증가분(전일 마지막 샘플 대비). 런칭일은 0에서 시작. 작품 색상 규칙은 시간별 차트와 동일

속성별 인기 (공·수·남·녀 / 태그)

속성 태그 = 어미가 공·수·남·녀인 태그(집착공·미인수·능글남·유혹녀 등). 막대 색은 태그 어미의 역할색, 회색은 설정 태그(학원물·BL 등). 태그는 API 원값 그대로 표기

한 캐릭터는 자기 태그 전부에 기여하므로 태그 간 합계는 중복된다. 캐릭터 수가 적은 태그는 한 명의 영향이 크다(n 표시). 집착공과 집착남은 별개 태그로 취급하며 어미를 떼어 비교하지 않는다.

캐릭터 순위

헤더를 눌러 정렬. 순위는 누적 기준 고정. 스파크라인은 최근 24개 시간 구간 증가량

작품별 집계

데이터: data.js (collect.py가 10분마다 재생성, 원본 teaz.db / counts.csv) · 이벤트 마커: events.js
출처: GET api.myteaz.io/chat/rooms의 entry_character.message_count, like_count · 집계 시각은 KST
